# Number-Gesture-Model
A YOLO based object detection model able to detect number hand gestures 1 - 5. Based on the yolo11s.pt, this model was trained on 800 images of number hand gestures.

To use this, make sure ultralytics is downloaded in your system. Further information is located here: https://docs.ultralytics.com/quickstart#headless-server-installation

Step by step guide on usage:
1. Make sure ultralytics is downloaded in your system
2. Download either Nums_Model3.pt or 1-5_Nums_Model2.pt
3. Make a python file in the same loacation as any of the model in No.2
4. Run the code inside predict.py in your python file in No.3
